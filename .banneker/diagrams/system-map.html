System Architecture Map

Component breakdown and responsibilities

⚙️

Core Infrastructure

Platform detection, package installation, dotfile linking

  • install.sh — multi-platform installer
  • link_dotfiles.sh — symlink orchestrator
  • Dockerfile — container definition
  • docker-compose.yml — service orchestration
🐚

Shell Configuration

Zsh/Bash setup with plugins and prompt

  • .zshrc — Zsh config (oh-my-zsh)
  • .bashrc — Bash config
  • .bashrc_mac — macOS-specific Bash
  • zsh-autosuggestions plugin
  • starship prompt
🖥️

Terminal Multiplexer

tmux sessions, plugins, and switching

  • .tmux.conf — tmux configuration
  • tpm — plugin manager
  • switch-session-fzf.sh — fzf session picker
✏️

Editors

Helix and Neovim modal editors

  • .config/helix/config.toml — Helix settings
  • .config/helix/languages.toml — LSP config
  • neovim — installed via apt/brew
🔍

Search & Navigation

CLI tools for finding files and content

  • fzf — fuzzy finder
  • ripgrep — fast grep
  • bat — syntax-highlighted cat
  • zoxide — smart cd
🐳

Docker Environment

Portable Linux container with all tools

  • Python 3.12-slim base
  • All tools pre-installed
  • Volume-mounted workspace
  • uv cache persistence
📱

Termux (Android)

Mobile development environment

  • .termux/ — Termux configs
  • chargectl — battery limiter
  • Magisk module — boot persistence
  • termux-api integration
🔐

Secrets & Config

Sensitive data and window manager configs

  • .secret_sample → ~/.secret
  • .gitconfig — Git configuration
  • .config/aerospace/ — macOS WM
  • glazevm/ — Windows WM config
